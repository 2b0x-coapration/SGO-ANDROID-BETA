# SGO Browser (Android 8+, tuned for Android 13)
Push this folder to GitHub -> Actions tab -> "Build APK" -> download artifact `SGO-apk`.
Or open in Android Studio and press Run.
Features: minimal purple UI, no home-screen sites/articles, custom Downloads page,
tap a downloaded APK to install it inside the browser (asks for "Install unknown apps" permission once),
settings (theme, search engine, suggestions), favorites, history, share.
